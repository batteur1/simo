SIMO — جاهز للنشر (Render مجاني + Neon PostgreSQL مجاني)
الشعار: الأصلي (دبوس الموقع + حرف S)

== خطوات النشر ==
1) Neon.tech: أنشئ مشروعًا وانسخ Connection string (DATABASE_URL).
2) GitHub: ارفع كل الملفات إلى جذر مستودع جديد (بدون node_modules).
3) Render: New > Blueprint > اختر المستودع، ثم أدخل:
   DATABASE_URL  = رابط Neon
   ADMIN_PHONE   = رقم هاتفك (06xxxxxxxx) — يصبح مدير النظام تلقائيًا
   TWILIO_SID / TWILIO_TOKEN / TWILIO_FROM = لإرسال رمز SMS الحقيقي
4) Apply. بعد دقائق يعمل الموقع على https://<name>.onrender.com

== بدء العمل ==
- الزبائن: الصفحة الرئيسية /
- الإدارة والتجار والموزعون: /staff.html (سجّل بنفس رقم ADMIN_PHONE)
- من لوحة الإدارة: فعّل المدن، أضف المتاجر والمنتجات والصور، أكواد الخصم،
  وعيّن أدوار التجار والموزعين من تبويب «الفريق».

== تنبيهات مهمة ==
- DEV_OTP=0 في الإنتاج. إن لم تُضبط Twilio لن يصل أحد إلى الدخول.
  للتجربة فقط ضع DEV_OTP=1 (يظهر الرمز على الشاشة وتُنشأ حسابات اختبار
  0600000001..04 بما فيها «إدارة»)، ثم أعده إلى 0 قبل الإطلاق.
- الخطة المجانية في Render تنام بعد 15 دقيقة بلا زيارات (أول طلب بطيء).
